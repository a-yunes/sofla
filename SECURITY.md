# Security

Do not post vulnerabilities containing private data or working exploits in public issues.
Use the repository's private vulnerability reporting feature once the public repository opens.
If it is unavailable, ask a maintainer for a private channel without sharing exploit details.

Sofla has no network service or telemetry. Layouts and recent-app history stay locally in
`~/Library/Application Support/Sofla`. Include only sanitized fixtures in bug reports.
