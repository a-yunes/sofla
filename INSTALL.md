# Install Sofla

Requires macOS 26 or later and Apple silicon.

This release is not notarized by Apple. macOS may block its first launch.

1. Download the disk image from the repository's Releases page.
2. Drag Sofla to Applications, then open it from there.
3. If blocked, open System Settings > Privacy & Security and choose Open Anyway for Sofla.
4. Confirm Open only if you trust the download. Then choose a shortcut in setup.

Open at Login is optional. Basic launching needs no Accessibility, Screen Recording,
or Full Disk Access permission. Managed Macs may prevent first-launch approval.

For updates, use Sofla > Check for Updates. Optional automatic checks and installation are in
Settings > Updates. Update checks contact GitHub; your app library stays local. You can also
quit Sofla and replace it manually in Applications. Your local layout is preserved.
To remove it, turn off Open at Login, quit, and move Sofla from Applications to Trash.

[Apple's first-launch instructions](https://support.apple.com/en-gb/102445).
