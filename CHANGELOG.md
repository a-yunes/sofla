# Changes

## 1.0.0 · October 12, 2026

- Native full-screen app grid, search, folders, Favorites, and Recents.
- Optional Open at Login and a configurable keyboard shortcut.
- Local data, no account, and no analytics.
- Apple silicon with a macOS 26 minimum.
- Styled drag-to-Applications installer with a verified background and icon layout.
- Signed software updates with optional automatic checks and installation.

This release is ad-hoc signed and not notarized by Apple. See [installation steps](INSTALL.md).
