# Reliability and performance

Status: DONE

Stable catalog identities, stale-result handling, cache bounds, persistence recovery,
and cancellation have regression coverage. Arrow keys navigate search results while
preserving text editing shortcuts and input-method composition.

Release benchmarks use synthetic records and separate search computation from native
presentation. Desktop automation requires a working logged-in session. Compilation alone
does not prove UI acceptance.

See [the active plan](004-release.md) for current measurements and validation.
